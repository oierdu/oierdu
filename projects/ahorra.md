# Ahorra Aislando

Web de servicios, proceso, contacto y páginas legales. React 19, Vite, Tailwind CSS y Framer Motion. Desarrollo en colaboración; se conserva la autoría del código original.

## Evidencia y límites

La compilación Vite se ha ejecutado correctamente y la interfaz pública se ha revisado. El contacto utiliza mailto; no se afirma envío automático de correo ni CAPTCHA verificado. No se atribuyen al desarrollo las estimaciones comerciales de ahorro publicadas en la web.
